SM ONLINE STORE
================

Open index.html to preview the store.

FEATURES
- Black and white responsive theme
- Men, Women, Kids and Accessories sections
- Product images included locally
- Prices displayed in KSh
- Sign-in demo saved in browser localStorage
- Shopping cart with quantity controls
- Place-order checkout form
- WhatsApp ordering/contact
- Help section

IMPORTANT: SET YOUR WHATSAPP NUMBER
-----------------------------------
Open app.js and change:
const WHATSAPP_NUMBER = '254700000000';

Replace 254700000000 with the store's real WhatsApp number, country code included and without + or spaces.
Example Kenya format: 2547XXXXXXXX

GITHUB PAGES
------------
Upload the entire SMONLINESTORE folder to your GitHub repository, keeping the images folder and all files together. Enable GitHub Pages from Settings > Pages and select the main branch/root.

NOTE
----
This is a front-end store. The sign-in is a browser-only demo and does not create real server accounts or process payments. Orders are sent through WhatsApp.
